## 统一设计基线

- 白色/暖灰背景，细灰色边框，轻阴影，克制的 Aino 蓝色强调色。
- 左侧一级结构沿用母版：`会话`、`机器人`、`新建会话`、`历史会话`、`文件管理`、`消息中心`、`设置`、`最近会话`。
- 界面文案以中文为主；斜杠命令、代码、文件路径、协议名和模型 ID 保留英文。
- 具体按钮尺寸、间距、状态色和键盘焦点样式，需在实现阶段转为可复用 design tokens。
